# LittleFox

Making karaoke videos in a comfortable way.

Fast synthesis subtitle with audio or video without traditional boring works. Making "karaoke style" videos with dynamic text on single character level, very suitable for music videos making, two lines of text simultaneously display is designedly ready for language learning videos making. LittleFox helps people share music videos on social websites in a very efficient way. With the help of the app, you can burn your favourite mp3 to video with lyrics sheet in several minutes, make slideshows by merging pictures with speech audio, synchronise lyrics with an existing video, and easily share the final video with a more smaller file size.

Each synthesis type can put the subtitle in the bottom of the outside margin without video area overlay. Preview every label on each single character for Karaoke style, subtitle can be spitted into two type of content and each type of content can has different font and colour.

Using an alternative Latin font in such situations:
a. When synthesis subtitle with Kanji text line and a paired translated Latin text line, because the Latin text line always require more space, so user can use this option to set up a smaller font for the pure Latin text lines if those lines are too long.
b. When synthesis subtitle with Kanji font, but you don't want to use the style of latin characters in that font, then check on this option to use an alternative font for non-Kanji characters.

Since 2019, this small utility have helped the author creating hundreds of high quality music videos.
